# Junzle Brand Assets & Logo Specifications

Official vector assets, revised logo marks, app icons, and favicons for the Junzle platform.

## Color Tokens
- **Royal Blue (Primary):** `#1A56DB`
- **Canary Yellow (Accent):** `#FFEF00`
- **Dark Navy:** `#0D1B3E`
- **White:** `#FFFFFF`

## Files Included
- `logo-white-bg.svg` — Revised single bold italic J in Royal Blue with canary yellow negative space cut on white background.
- `logo-dark-navy-bg.svg` — Dark Navy background version of revised logo.
- `app-icon-blue.svg` — Standalone iOS app icon on Royal Blue rounded square.
- `app-icon-white.svg` — Standalone iOS app icon on White rounded square.
- `favicon-60x60.svg` & `favicon-120x120.svg` — Scaled favicons.
- `BrandAssetsPreview.html` — Interactive preview sheet. Double-click or open in any web browser to view all assets and contrast checks.
